## 旧计划中不能继续照抄的方案

- “焦点非空”不证明焦点在目标窗口，更不证明是目标字段；RIGHT 在已有选区上不是无副作用键。
- PrintWindow 与元素数只提供有限观察，不能证明真实屏幕没变或业务没执行；采样无变化不能触发重放。
- AllowSetForegroundWindow 是允许指定进程设置前台，不是防止其抢前台的保护机制。
- cause_unknown=true 的 pattern unavailable 不能直接作为 provider 不支持的证据。
- 新增桌面切换工具不等于把 UIA worker/旧目标隔离，也不等于完成只读预览。
- 文档少于 300 行、禁止数字、plan 少于 1500 字符都不是指导质量的行为验收。

## 本轮实现范围与验收方式

保留现有公共工具和存储格式，不增加依赖，不迁移真实记忆，不替用户执行应用实验。
每个代码缺陷先新增会失败的行为回归，再做最小修复：

- 输入：正文花括号经过真实 SendKeys parser 时保持字面值；有旧值能替换，空正文能清空；
  目标未持焦点、正文前失焦或等待越过预算时停止输入。
- 读回：模拟真实 WM_GETTEXT 的 wParam-1 边界，额外后缀和空串均不能误报完整写入成功。
- 启动/桌面：重显窗口继续核验隐藏，最终可见不报 applied；父 PID 链按每级创建时间验证；
  切回失败保留会话，可在错误解除后重试。
- 卸载：在临时 USERPROFILE 中执行脚本、替换系统任务/进程 API，验证首/中/末节和子节删除，
  其他服务器配置不变，其他 Root/同名参数进程不被选中。
- worker/记忆：实际 _spawn 超时分支干净回收后可再次尝试；缺失 app@unversioned 不回退旧版本。
- 指引：11 类操作卡、实际 MCP schema 校验的示例、原值恢复和 150 条重叠分页完整流程；
  独立操作者在异步未知、私有桌面、同名分页、文本截断和恢复失配情境下检验下一步。

修订前工作区离线基线为 430 项、426 通过、4 失败，其中三项是草稿的行数/禁数字冲突，
一项是资源测试把 __pycache__ 算成分发文件。修订不以删除必要内容迁就这些指标。
本轮真实 GUI、已安装 HTTP 服务和各应用兼容矩阵均未执行；完整离线结果随交付记录。
